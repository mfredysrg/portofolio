Perancangan Aplikasi E-Commerce Berbasis Website dan Mobile Pada Toko Citra Kosmetik

Universitas Malikussaleh - Program Studi Sistem Informasi

Core Competencies / Technologies & Focus

Mobile & Website Platform Database Management (ERD) Software Development Life Cycle (SDLC) Black Box Testing
[ Tempat Screenshot / Dokumentasi Projek Toko Citra Kosmetik ]

Latar Belakang Masalah

Perkembangan teknologi informasi telah mendorong transformasi digital di berbagai sektor ritel, termasuk industri kosmetik[cite: 2]. Toko Citra Kosmetik yang berlokasi di Desa Batuphat, Kota Lhokseumawe, sebelumnya masih mengandalkan sistem pemasaran konvensional[cite: 2]. Hal ini menimbulkan beberapa kendala seperti keterbatasan akses informasi produk bagi pelanggan, antrean di toko fisik, serta terbatasnya variasi metode pembayaran[cite: 2]. Oleh karena itu, diperlukan perancangan sistem e-commerce terintegrasi untuk memperluas jangkauan pasar dan meningkatkan efisiensi operasional[cite: 2].

Metode / Teknologi yang Digunakan

A. Metode Pengumpulan Data: Menggunakan metode observasi langsung terhadap aktivitas operasional toko, wawancara mendalam dengan pemilik serta staf terkait kebutuhan sistem, dan studi pustaka dari berbagai literatur ilmiah[cite: 2].

B. Model Pengembangan Sistem (SDLC): Menerapkan model Software Development Life Cycle (Waterfall) yang meliputi tahapan Analisis Kebutuhan Sistem, Perancangan Sistem (Desain ERD, Use Case, dan Activity Diagram), Penulisan Kode Program (Coding), hingga Pengujian Program[cite: 2].

C. Arsitektur & Fungsionalitas Platform: Dibangun menjadi dua platform utama secara terpusat, yaitu aplikasi berbasis website untuk admin (pengelolaan data produk, kategori, stok masuk/keluar, promo, manajemen pesanan, dan cek resi) serta aplikasi mobile untuk pengguna/konsumen (katalog produk, keranjang belanja, proses checkout, metode pembayaran, fitur favorit, hingga layanan live chat interaktif)[cite: 2].

D. Pengujian Sistem: Menggunakan metode Black Box Testing untuk memastikan seluruh fungsionalitas menu pada sisi admin maupun user berjalan dengan valid tanpa kendala[cite: 2].

Hasil & Kesimpulan

A. Hasil Akhir Sistem: Berhasil merancang dan mengimplementasikan aplikasi e-commerce hibrida (Website Admin & Mobile User) yang responsif dan user-friendly bagi Toko Citra Kosmetik[cite: 2]. Pengujian fungsionalitas menggunakan Black Box Testing membuktikan bahwa seluruh menu pengujian (seperti login, manajemen produk, transaksi, keranjang, hingga chat) berhasil berjalan dengan status "berjalan/valid"[cite: 2].

B. Kesimpulan: Penerapan sistem ini berhasil memberikan fleksibilitas penuh bagi konsumen dalam mengakses produk, melakukan pemesanan, dan transaksi secara daring kapan saja, serta membantu pemilik toko dalam memusatkan pengelolaan data serta meningkatkan daya saing bisnis di era digital[cite: 2].
