Project / Mata Kuliah E-Commerce

Perancangan Aplikasi E-Commerce Berbasis Website dan Mobile Pada Toko Citra Kosmetik

Universitas Malikussaleh - Program Studi Sistem Informasi

Core Technologies & Architecture

Web Application (Admin) Mobile Application (User) Database Management (ERD) Software Development Life Cycle (SDLC)

Latar Belakang Masalah

Transformasi digital di sektor ritel kosmetik sangat didorong oleh pesatnya kemajuan teknologi informasi. Pada Toko Citra Kosmetik (berlokasi di Desa Batuphat, Kota Lhokseumawe), proses penjualan konvensional masih menghadapi berbagai kendala seperti keterbatasan akses informasi produk bagi pelanggan, antrean langsung di toko, serta keterbatasan pilihan metode pembayaran. Oleh karena itu, diperlukan sistem e-commerce terintegrasi untuk memperluas jangkauan pasar dan meningkatkan efisiensi operasional.

Metode / Teknologi yang Digunakan

A. Metode Pengumpulan Data: Menggunakan metode observasi langsung kegiatan operasional toko, wawancara mendalam dengan pemilik dan staf, serta studi pustaka terkait desain UI/UX dan sistem e-commerce.

B. Model Pengembangan Sistem (SDLC): Menerapkan model Waterfall yang terstruktur, mencakup tahapan Analisis Kebutuhan Sistem, Perancangan Sistem (Desain ERD, Use Case, Activity Diagram), Penulisan Kode Program (Coding), hingga Pengujian Program.

C. Arsitektur Dual-Platform: Membangun dua sistem terpusat yaitu aplikasi berbasis website untuk admin (manajemen produk, stok masuk/keluar, promo, dan laporan transaksi) serta aplikasi berbasis mobile untuk konsumen (katalog, keranjang, checkout, pembayaran, dan live chat).

Hasil & Kesimpulan

A. Hasil Pengujian Sistem: Berdasarkan pengujian fungsionalitas menggunakan metode Black Box Testing pada menu admin dan user, seluruh fitur utama mulai dari proses login, manajemen kategori, pengelolaan produk, transaksi keranjang, hingga pelacakan resi dinyatakan berjalan valid dan sukses tanpa kendala.

B. Kesimpulan: Implementasi aplikasi e-commerce berbasis website dan mobile ini sukses memberikan solusi fleksibel bagi konsumen dalam mengakses produk kosmetik sekaligus membantu toko mengotomatisasi manajemen data secara terpusat dan akurat.
